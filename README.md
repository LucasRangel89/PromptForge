# PromptForge

Estúdio interativo de direção criativa para construir, refinar, salvar e exportar prompts de imagem.

- Aplicação atual: [`promptforge/`](./promptforge/)
- Diagnóstico do repositório e roadmap: [`ANALISE_DO_REPOSITORIO.md`](./ANALISE_DO_REPOSITORIO.md)
- Documentação técnica e execução: [`promptforge/README.md`](./promptforge/README.md)

## Início rápido

```bash
cd promptforge
npm install
npm run dev
```

A interface fica disponível em `http://localhost:3000`. O gerador de prompts funciona sem chave de API; o refinamento por IA é opcional.
